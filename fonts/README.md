# Font Files

Place your font files in this directory.

The script expects:
1. A bold font (e.g., `Montserrat-Bold.ttf`)
2. A regular font (e.g., `Montserrat-Regular.ttf`)

Update the `FONT_BOLD_PATH` and `FONT_REGULAR_PATH` variables in `main.py` to match your font filenames.

## Recommended Fonts

- **Montserrat** (free on Google Fonts)
- **Poppins** (free on Google Fonts)
- **Inter** (free on Google Fonts)
- **Roboto** (free on Google Fonts)

Download the `.ttf` files and place them in this directory.
